# Объекты и задачи — мини-CRM для строительной компании

Тестовое задание для 2B Studio. React + TypeScript + Vite, Supabase (Postgres + RLS).

> README будет дополнен в конце работы (структура, доступы, проверка безопасности).

## Запуск локально

```bash
pnpm install
cp .env.example .env   # заполнить VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
pnpm dev               # http://localhost:5173
```

Решения и допущения — [`docs/decisions.md`](docs/decisions.md).
